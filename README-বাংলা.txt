নগদ ডেমো Android প্রজেক্ট

এটি একটি অনানুষ্ঠানিক শিক্ষামূলক ডেমো। এটি আসল Nagad অ্যাপ নয় এবং কোনো বাস্তব অর্থ, অ্যাকাউন্ট, OTP, PIN বা পেমেন্ট সিস্টেমের সাথে সংযুক্ত নয়।

APK তৈরি করার নিয়ম:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ZIP ফাইলটি Extract করুন।
3. Android Studio থেকে Extract করা NagadDemoAndroid ফোল্ডারটি Open করুন।
4. Gradle Sync সম্পন্ন হতে দিন (প্রথমবার ইন্টারনেট লাগবে)।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
6. APK তৈরি হলে Android Studio-এর notification থেকে Locate চাপুন।

প্রজেক্টের package: com.example.nagaddemo
অ্যাপের নাম: Nagad Demo

নোট: এই পরিবেশে Android SDK/Gradle build চালিয়ে APK কম্পাইল করা সম্ভব হয়নি; তাই ZIP-এ Android Studio source project দেওয়া হয়েছে, সরাসরি ইনস্টলযোগ্য APK নয়।
